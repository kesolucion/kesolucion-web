# Dirección de marca inicial

Kesolucion: ideas claras, sistemas que conectan. Voz cercana y concreta, dirigida a quienes administran centros educativos, universidades y negocios. Mensaje principal: «Menos complicaciones. Más posibilidades.»

## Paleta

| Uso                                     | Color     |
| --------------------------------------- | --------- |
| Violeta intenso, identidad y acciones   | `#6434E8` |
| Violeta profundo, secciones comerciales | `#251547` |
| Lima eléctrico, acentos y SISAC         | `#D8FF56` |
| Blanco cálido, fondo principal          | `#FCFAFF` |
| Tinta violeta, texto principal          | `#24153E` |
| Lavanda, UCAJUP                         | `#D6C0FF` |
| Coral, inventario                       | `#FF987E` |
| Cian, reportes                          | `#80E5F4` |

La paleta está centralizada en `src/styles/theme.css`. El hero combina lavanda y coral; el contacto usa un degradado violeta. Los acentos brillantes se acompañan de texto oscuro y las secciones intensas de texto claro.

Manrope para titulares y marca; DM Sans para lectura e interfaz. Símbolo inicial: una k con dirección ascendente. La identidad es una propuesta inicial editable.

## Estructura comercial

Promesa de valor → segmentos → catálogo por necesidad → detalle y solicitud de demo → forma de trabajo → preguntas que reducen dudas → contacto. CTA principal: encontrar una solución; CTA de intención alta: solicitar una demostración. Sin precios inventados, testimonios ficticios ni métricas de resultados.

## Siguientes activos

Capturas reales sin datos personales, demostraciones verificadas, condiciones comerciales y testimonios autorizados. El sitio no afirma certificaciones ni disponibilidad permanente.
